# Submission checklist

## Before the 30 September milestone

- [ ] Join ARC-AGI-3 and accept the binding Kaggle rules.
- [ ] Confirm solo identity is identical across code and Paper Track teams.
- [ ] Pass offline startup and competition-mode lifecycle tests.
- [ ] Verify `manifest.sha256`, every payload hash, and extracted wheel license inventory.
- [ ] Project hidden workload at p95 below 80% of the actual Kaggle runtime limit.
- [ ] Publish source, model/config hashes, dependency lock, and third-party notices.
- [ ] Submit the strongest gate-compliant milestone configuration.

## Before 26 October entry lock

- [ ] Recheck live entry, team-merger, hardware, and licensing rules.
- [ ] Obtain or record the organizer response on MIT-0/CC-BY-4.0 wording.
- [ ] Freeze repository commit and all model/data artifact hashes.

## Before 2 November code deadline

- [ ] Run one full competition-mode rehearsal with no internet.
- [ ] Use an operating-system network boundary; Python offline flags alone are insufficient.
- [ ] Ensure each environment is made once and only one scorecard is opened.
- [ ] Ensure only level resets occur and no inflight score is queried.
- [ ] Select the final code submission and record its submission ID.

## Before the 8 November safety deadline

- [ ] Kaggle Writeup is 1,400–1,450 words and explicitly submitted, not merely saved.
- [ ] Title, subtitle, selected track, linked submission ID, and detailed analysis present.
- [ ] Public notebook works without authentication or paid services.
- [ ] Media Gallery and cover image attached.
- [ ] Claims match passed gates and private score exactly.
- [ ] Make the single deliberate final Paper Track submission.
