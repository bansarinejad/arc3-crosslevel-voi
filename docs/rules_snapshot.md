# Rules snapshot — 12 July 2026

This file is a planning aid, not a substitute for the binding Kaggle rules.

- Paper submissions must link a real ARC-AGI-2 or ARC-AGI-3 Kaggle code submission.
- Paper and linked code teams must match.
- Six categories are equally weighted: Accuracy, Universality, Progress, Theory,
  Completeness, and Novelty.
- A complete Kaggle Writeup, public notebook, media gallery, and cover image are the safe
  submission path. Do not rely on a PDF-only interpretation.
- Target at most 1,500 words; this repository targets 1,400–1,450.
- Competition evaluation has no internet access.
- ARC-AGI-3 entry deadline: 26 October 2026, 11:59 UTC.
- Code deadline: 2 November 2026, 23:59 UTC.
- ARC lists papers due 8 November; Kaggle lists 9 November, 23:59 UTC. Use 8 November.
- Competition-specific wording permits one final Paper Track submission per team.
- Only the $75,000 top-three Paper Track pool is guaranteed; the outstanding-paper pool
  above 4.5 is discretionary.

Recheck the live pages and archive a dated copy before every submission milestone.
